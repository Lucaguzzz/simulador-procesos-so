# ProcessSchedulerSim

## Descripción
ProcessSchedulerSim es una herramienta interactiva de consola diseñada para simular la planificación de procesos en sistemas operativos multitarea. El software permite comparar el rendimiento de algoritmos como Round Robin, Prioridades y SJF (Shortest Job First), calculando métricas en tiempo real como el tiempo de espera promedio, tiempo de retorno y uso de CPU. Está dirigido a estudiantes y profesores de ciencias de la computación como recurso didáctico.
